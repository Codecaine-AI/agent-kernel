# Demo Positioning Notes

- A research agent is a useful base demo because the input and output are familiar: ask a question, wait for work, receive a report.
- Subagents are easy to explain as focused scouts that gather reports for the final synthesis.
- Working memory makes the run tangible because users can inspect generated scout reports and final reports on disk inside the run's research session directory.
- The trace viewer can show the whole story: prompt resolution, context loading, tool calls, nested subagents, and final assistant output.
