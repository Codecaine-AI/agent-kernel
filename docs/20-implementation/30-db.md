# Database Package

`@agent-kernel/db` owns kernel observability storage: the client and bootstrap for the per-kernel SQLite database, the kernel manifest helpers, the Drizzle schema (containers, Pi agent sessions, agent runs, trace events, prompt revisions, trace blobs), and the write actions and container-first read helpers over it.

Source: `packages/db/src/` — `client.ts`, `manifest.ts`, `bootstrap.ts`, `schema/`, `actions/`.

Governed by: [20-observability-model.md](../10-system-design/20-observability-model.md) (records, storage behavior, identity, rollups, idempotent inserts).

---

## Decisions

### SQLite-first actions; the Postgres mirror is schema-only, behind a subpath

**Decision.** The actions layer is typed against the Bun-SQLite Drizzle handle. The Postgres mirror of the schema — matching column names, row shapes, and constraints, timestamps staying ISO-8601 TEXT — is exported only through the `schema/pg` subpath; Postgres deployments query the mirrored tables directly until actions go dual-dialect.

**Why.** Shared-plane deployments need the table shapes now; making every action dual-dialect now was rejected as cost without a consumer. The subpath keeps the default entrypoint SQLite-only so nothing accidentally depends on the mirror.

**Applies to.** `packages/db/src/schema/pg.ts` and every future action: new actions are written SQLite-first, and new tables must be added to both schemas with matching shapes.

### Idempotent bootstrap instead of migration tooling

**Decision.** `ensureKernelObservabilitySchema(db)` runs `CREATE TABLE IF NOT EXISTS` statements mirroring the Drizzle schema on every kernel start. There is no migration framework.

**Why.** The database is local, per-kernel, and rebuildable from JSONL via backfill — migration tooling was rejected as machinery without a payoff at this scale. The consequence is a rule, not a convenience: schema changes must be expressible as idempotent creation (new tables, additive columns with defaults), and a change that needs a data migration needs a design decision first.

**Applies to.** `packages/db/src/bootstrap.ts`, `schema/`, and every future schema change.
